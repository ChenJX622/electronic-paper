# 🖼️ 智能语音相框 (Renesas RA6M5)

> 基于瑞萨 **RA6M5** (R7FA6M5BH) + **FSP** 的智能语音交互相框系统

一个会「看人」也会「听话」的相框：**有人靠近自动唤醒并显示**，**挥一挥手**或**说一句话**就能切换画面，无人时自动轮播。

---

## ✨ 功能特性

| 功能 | 实现方式 |
|------|----------|
| 👤 **人体感应唤醒** | HC-SR501 红外传感器 + 防抖状态机 |
| 📳 **摇晃切图** | MPU6050 六轴 IMU，加速度差分阈值检测 |
| 🎤 **语音切图** | ASR PRO 离线语音识别模块（UART5，9600 bps） |
| 🔊 **语音播报** | SNR9816 TTS 模块，支持 UTF-8 中文、男女声、音量/语速/语调可调 |
| 🖥️ **画面显示** | 串口屏（淘晶驰 TJC 协议），6 页画面 |
| 🎧 **音频采集** | MAX9814 麦克风 + ADC + GPT 定时器，16 kHz 采样、20 ms 一帧 |
| 🔗 **双芯协作** | 通过 UART 自定义帧协议与 ESP32 通信，音频帧上传、识别结果回传 |

## 🧠 状态机设计

```
        ┌────────────────────────────────────────┐
        │          无人模式（自动轮播）            │
        │      每 2 秒切换下一张，共 6 张画面       │
        └────────────────┬───────────────────────┘
                         │ 红外连续 5 次检测到人
                         ▼
        ┌────────────────────────────────────────┐
        │          有人模式（保持 20 秒）          │
        │  显示第 1 页                             │
        │  只要持续有人，20 秒计时器【永久刷新】     │
        │  摇晃 / 语音「下一张」→ 立即切图          │
        └────────────────┬───────────────────────┘
                         │ 倒计时归零
                         ▼
                      回到无人模式
```

**核心设计要点**

- **防抖保护**：有人模式下，红外偶发丢失**不会**误判为无人，避免画面在有人时突然跳回轮播
- **优先级**：有人模式 > 进入有人模式 > 无人轮播，三级状态机清晰互斥
- **同级响应**：摇晃与语音切图在有人模式下同级，谁先触发谁生效

## 🔌 硬件连接

| 外设 | 接口 | 说明 |
|------|------|------|
| 串口屏 | UART9 | 发送 `page N` 指令切页 |
| ASR PRO 语音识别 | UART5 | 9600 bps |
| SNR9816 TTS 语音合成 | UART3 | P707 = TX，P706 = RX |
| ESP32（音频识别） | UART8 | 自定义帧协议 |
| 调试串口 | UART7 | `printf` 输出 |
| MPU6050 六轴 IMU | I2C2 | 从机地址 `0x68` |
| HC-SR501 红外 | P004 | 数字输入 |
| MAX9814 麦克风 | ADC | 16 kHz 采样 |

## 📡 与 ESP32 的通信协议

瑞萨端负责**采集音频并打包**，ESP32 端负责**语音识别**，识别结果回传瑞萨端。

### 瑞萨 → ESP32（音频帧）

| 字节 | 内容 |
|------|------|
| `0xAA` `0x55` | 帧头 |
| `0x01` | 帧类型：音频数据 |
| … | 16 位 PCM 采样数据（16 kHz，20 ms/帧 = 320 采样点） |
| `0xEE` | 帧尾 |

### ESP32 → 瑞萨（识别结果帧）

| 字节 | 内容 |
|------|------|
| `0xBB` `0x66` | 帧头 |
| … | UTF-8 识别文本（最长 256 字节） |
| `0x66` `0xBB` | 帧尾 |

> 超过 500 ms 未攒满一帧也会强制发送，保证语音响应实时性。
> 音频参数（采样率、帧长、噪声阈值）在 `audio.h` 中定义，需与 ESP32 端保持一致。

## 📁 目录结构

```
├── src/
│   ├── hal_entry.c          # 主程序：初始化 + 核心状态机
│   └── hal_warmstart.c
├── ra_gen/                  # FSP 自动生成的配置代码
├── ra_cfg/                  # FSP 配置头文件
├── ra/                      # Renesas FSP 与 CMSIS-DSP（厂商库）
├── script/                  # 链接脚本（.scat）
├── configuration.xml        # FSP 配置（用 RASC / e² studio 打开）
├── FSP.uvprojx              # Keil MDK 工程文件
│
├── display.c / .h           # 串口屏驱动（淘晶驰协议）
├── mpu6050.c / .h           # MPU6050 六轴 IMU 驱动
├── hscr501.c / .h           # 红外人体感应（防抖处理，沿用原工程文件名）
├── asr_pro.c / .h           # ASR PRO 语音识别
├── snr9816.c / .h           # SNR9816 TTS 语音合成
├── max9814.c / .h           # 麦克风驱动
├── audio.c / .h             # 音频采集、帧打包、结果解析
├── uart_comm.c / .h         # 与 ESP32 的通信协议
├── sensor_frame.c / .h      # 传感器数据结构与接口
├── ADC_MY.c / .h            # ADC 封装
└── dsp_process.c / .h       # 数字信号处理
```

## 🚀 编译与烧录

1. 安装 **Keil MDK** + **Renesas RA FSP Pack**（或 **e² studio**）
2. 用 **RASC** 打开 `configuration.xml`，确认外设配置：
   UART3 / UART5 / UART7 / UART8 / UART9、I2C2、ADC、GPT
3. 打开 `FSP.uvprojx` 编译工程
4. 用 J-Link / Renesas Flash Programmer 烧录

> ⚠️ 克隆仓库后，如果编译报错找不到 `ra/` 目录，用 RASC 重新 **Generate Project Content** 即可。

## ⚙️ 可调参数

| 参数 | 位置 | 默认值 | 说明 |
|------|------|--------|------|
| `HUMAN_HOLD_TIME_MS` | `src/hal_entry.c` | 20000 | 有人模式保持时间（ms） |
| `IMAGE_LOOP_DELAY_MS` | `src/hal_entry.c` | 2000 | 无人轮播间隔（ms） |
| `SHAKE_THRESHOLD` | `src/hal_entry.c` | 4000 | 摇晃触发阈值 |
| `HUMAN_DEBOUNCE_CNT` | `src/hal_entry.c` | 5 | 有人判定防抖次数 |
| `NO_HUMAN_DEBOUNCE_CNT` | `src/hal_entry.c` | 10 | 无人判定防抖次数 |
| `TOTAL_IMAGE_NUM` | `src/hal_entry.c` | 6 | 总画面数 |
| `ASR_CMD_NEXT_IMAGE` | `asr_pro.h` | 12 | 「下一张图片」语音指令 ID |
| `NOISE_THRESHOLD` | `audio.h` | 100 | 音频噪声过滤阈值 |
